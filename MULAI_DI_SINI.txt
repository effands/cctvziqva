MULTI CCTV - PAKET SIAP KIRIM (WINDOWS 10/11 64-BIT)

1. Ekstrak seluruh ZIP ke folder tetap di laptop tujuan.
2. Hubungkan laptop ke internet.
3. Jalankan install.bat. Ikuti petunjuk apabila Python/FFmpeg perlu
   dipasang manual atau laptop perlu direstart. Jangan abaikan peringatan
   instalasi: FFmpeg diperlukan untuk merekam dan Chromium untuk scanner.
4. Jalankan run_cctv_recorder.bat atau shortcut CCTV Recorder Jogja.
5. Buka http://localhost:8899 jika dashboard belum terbuka.

Daftar kamera dan pilihan aplikasi dipertahankan. Lokasi rekaman/backup
dibuat sesuai akun Windows di laptop tujuan saat install.bat dijalankan.
Rekaman dan backup lama tidak disertakan di paket; tetap ada di laptop asal.
Paket ini memerlukan instalasi dependensi dengan internet, bukan EXE mandiri.

Panduan lengkap: CARA_INSTALL.md
GUI desktop alternatif: python main_gui.py

SHA256SUMS.txt berisi checksum file untuk pemeriksaan integritas paket.
